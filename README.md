# Stella Duce

## 🌟 О проекте

Stella Duce (с латыни "Под руководством звезды") — это интеллектуальное приложение для планирования и достижения целей с использованием искусственного интеллекта. Приложение помогает пользователям не только ставить цели, но и создавать детальные пошаговые планы их достижения.

## 🚀 Основные возможности

### 1. Интеллектуальное планирование целей

Обсуждение целей с AI-ассистентом
Анализ и декомпозиция сложных задач
Генерация реалистичных и достижимых планов
### 2. Интерактивная Roadmap (карта пути)

Визуальное представление этапов достижения цели
Интерактивные узлы с возможностью отметки выполнения
Иерархическая структура задач и подзадач
Цветовая кодировка статусов выполнения
### 3. Управление прогрессом

Отметка выполненных этапов
Настройка статусов отдельных узлов
Визуализация прогресса в реальном времени
История изменений и достижений
### 4. Интегрированный календарь

Автоматическое распределение этапов по датам
Планирование дедлайнов
Уведомления о предстоящих задачах
Синхронизация с внешними календарями

## 🛠 Технологический стек

- Backend: Python (FastAPI)
- AI Integration: OpenAI GPT / Local LLM
- База данных: PostgreSQL

## 📱 Интерфейс приложения

### Основные экраны:

Главная страница - ввод и обсуждение целей
Roadmap Viewer - интерактивная карта пути
Календарь - временное планирование этапов
Профиль - статистика и история достижений

Предварительные требования:

````
# Клонирование репозитория
````

### 🎯 Как использовать

## Создание цели

Введите свою цель в диалоговом окне
Обсудите с AI возможные пути достижения
Уточните детали и ограничения
Генерация Roadmap

AI создаст детальный план с этапами
Настройте автоматически сгенерированные этапы
Определите приоритеты и зависимости
Работа с планом

Отмечайте выполненные этапы
Изменяйте статусы задач
Корректируйте сроки выполнения
Мониторинг прогресса

Следите за прогрессом на интерактивной карте
Используйте календарь для управления временем
Анализируйте статистику достижений
